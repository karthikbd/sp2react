# Code of Conduct

We want sp2react to be a project where anyone can ask a question, report a problem or contribute
without being made to feel unwelcome.

## Expected behaviour

- Be respectful and patient, including with people who are new to the project or to the technologies it
  touches (SharePoint, React, FastAPI, the model provider).
- Discuss ideas and code, not people. Critique is welcome when it is specific and constructive.
- Assume good intent, and ask before concluding otherwise.
- Respect people's time and privacy: don't share someone else's private information, and remove
  confidential data (host names, credentials, list data, page content) from logs before posting them.

## Unacceptable behaviour

- Harassment, insults, intimidation or personal attacks of any kind.
- Discriminatory language or conduct based on any personal characteristic.
- Sexual language or imagery, and unwelcome attention.
- Publishing others' private information without their permission.
- Sustained disruption of discussions, or encouraging any of the above.

## Scope

This applies in all project spaces (issues, pull requests, discussions, reviews) and when someone
represents the project elsewhere.

## Reporting and enforcement

Report a problem privately to the maintainer, Karthikeyan Balasundaram ([@karthikbd](https://github.com/karthikbd)),
using the contact details on that GitHub profile. If the report is sensitive you can also use the
repository's private reporting form (Security → Report a vulnerability); say in the title that it is a
conduct report. Reports are kept confidential.

The maintainer will review every report, may ask for more information, and will respond within 7 days.
Possible actions, depending on severity: a private warning, removal of the offending content, a
temporary or permanent ban from project spaces. If a report concerns the maintainer, it will be handled
by another maintainer once there is one; until then you may raise it with GitHub through its
[reporting tools](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
